Memuat preview…

Preview otomatis ditutup setelah 1 menit. Jika dialog simpan atau penulisan file masih berlangsung, penutupan menunggu sampai selesai atau dibatalkan.

Pilih nama dan folder tujuan pada dialog simpan. Chrome mengingat folder terakhir. Gulir hanya menulis satu PNG ke file pilihan, tanpa unduhan tambahan ke Downloads. Jika nama sudah ada, periksa konfirmasi penggantian file pada dialog.

Hasil disimpan sebagai satu PNG utuh. Panel gulir vertikal yang didukung diperluas sementara. Muat konten lazy-load dahulu. Selama pengambilan, jangan berpindah tab atau menggulir. Video, animasi, dan area scroll di dalam halaman memiliki keterbatasan.
