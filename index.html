Ruang lingkup

Kebijakan ini menjelaskan perilaku ekstensi Gulir versi 1.2.9. Gulir mengambil screenshot halaman web yang Anda pilih, menampilkannya dalam preview dan menyimpan PNG ketika Anda meminta. Tidak diperlukan akun Gulir.

Data yang diproses

Saat Anda menekan ikon atau shortcut, Gulir membaca informasi tab aktif untuk memeriksa apakah halaman didukung, mengukur tata letak/ukuran halaman, menyesuaikan sementara gaya dan posisi gulir, serta menangkap piksel halaman. URL dan judul tab dapat diakses selama tindakan ini, tetapi tidak disimpan sebagai riwayat browsing. Nama otomatis didasarkan pada waktu lokal, bukan judul halaman.

Screenshot berisi konten yang Anda pilih. Konten itu dapat memuat data pribadi, komunikasi, informasi keuangan, kesehatan, lokasi atau informasi sensitif lain jika terlihat pada halaman. Gulir tidak secara khusus mencari data tersebut dan tidak mengambil password atau cookie melalui API; informasi yang terlihat dalam gambar tetap dapat tercakup. Jangan mengambil atau menyimpan halaman yang tidak ingin Anda salin.

Di penyimpanan lokal extension (IndexedDB), Gulir menyimpan gambar PNG sementara, ID capture acak, waktu pengambilan, nama otomatis, dimensi, informasi capture, peringatan atau pesan kesalahan untuk membuka preview.

Gulir juga menyimpan preferensi simpan cepat, nama folder dan nama file dari penyimpanan terakhir yang berhasil. Bila simpan cepat diaktifkan dan Anda memilih direktori, Gulir menyimpan FileSystemDirectoryHandle lokal untuk memakai kembali folder sesuai izin Chrome. Chrome memberi nama folder, bukan path lengkap Windows/Linux.

Tujuan dan izin

Data hanya dipakai untuk screenshot, preview, penamaan file, pemilihan lokasi dan penyimpanan yang Anda minta. activeTab memberi akses informasi tab setelah tindakan pengguna; debugger digunakan untuk pengukuran halaman, pengguliran sementara dan screenshot. Chrome dapat menampilkan banner debugging. Gulir berusaha memulihkan tampilan/posisi halaman dan melepas sambungan debugger setelah capture, termasuk ketika terjadi kesalahan. Situs dapat menjalankan JavaScript atau memuat kontennya sendiri ketika digulir.

Tidak ada transmisi oleh Gulir

Gulir tidak mengunggah screenshot atau data preview ke server, tidak memakai analytics, iklan, pelacakan browsing di latar belakang, atau kode jarak jauh. Gulir tidak menjual maupun mengirim data pengguna kepada pihak ketiga. Situs yang Anda buka, browser dan layanan sinkronisasi/backup folder yang Anda pilih tetap bekerja sesuai pengaturan dan kebijakan masing-masing. Menyimpan PNG ke folder yang disinkronkan dapat menyebabkan layanan folder tersebut mengunggahnya di luar kendali Gulir.

Retensi dan penghapusan

Capture yang berumur lebih dari 24 jam dibersihkan pada capture berikutnya atau startup Chrome. Ini bukan penghapusan tepat setelah 24 jam; record dapat bertahan lebih lama bila pemicu tersebut belum terjadi. Menutup preview tidak langsung menghapus record.

Preferensi simpan cepat, handle direktori tersimpan dan metadata lokasi terakhir tidak mengikuti pembersihan 24 jam. Mematikan simpan cepat menghentikan penggunaan otomatis folder, tetapi tidak menghapus handle atau metadata lokasi yang telah disimpan. Mode biasa tetap meminta pemilihan folder dan browser dapat memakai folder lama sebagai titik awal dialog. Menghapus extension melalui Chrome menghapus data penyimpanan extension menurut perilaku Chrome. Anda dapat memasang ulang untuk memulai dengan penyimpanan baru.

PNG yang telah disimpan menjadi file di folder pilihan Anda dan tidak dihapus ketika preview ditutup atau extension dihapus. Hapus sendiri melalui pengelola file. Tidak ada tombol penghapusan seluruh data dalam UI Gulir 1.2.9.

Keamanan dan kendali Anda

Penulisan dilakukan melalui File System Access setelah tindakan Simpan/Enter dan izin folder dari browser. Simpan cepat nonaktif secara bawaan. Gulir tidak menambah enkripsi tersendiri pada IndexedDB atau PNG yang diekspor; perlindungan bergantung pada perangkat, profil browser dan izin file Anda. Jaga keamanan perangkat dan lokasi penyimpanan, terutama untuk gambar yang memuat data sensitif.

Kepatuhan penggunaan terbatas

Penggunaan informasi yang diterima melalui API Google mengikuti Chrome Web Store User Data Policy, termasuk persyaratan Limited Use. Data tidak digunakan untuk iklan yang dipersonalisasi, penilaian kredit atau pinjaman.

Kontak dan perubahan

Untuk pertanyaan privasi, hubungi kontak pengelola di atas. Kebijakan dan listing perlu diperbarui sebelum perilaku data berubah.
